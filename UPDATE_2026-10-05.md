# Map-first explorer update — 5 October 2026

The full-viewport map uses a compact floating identity, Bangkok clock, area shortcuts and a bottom dock. Routes, service reports, cameras and map settings appear on demand. Fares and time controls remain available. The train time panel still fades after 2.5 seconds when not being used; phone layouts hide rotation/zoom buttons and retain touch gestures. Building opacity is reduced so routes and station names stand out.

## Camera source

- Sukhumvit Soi 11 / El Gaucho: [The Real Samui Webcam](https://www.youtube.com/watch?v=UemFRPrl1hk), verified live on 5 October 2026. The Netlify preview played street footage with the provider's 05-10-2026 14:27 ICT timestamp. Embedded with the standard YouTube privacy-enhanced player. Video loads only on play and is removed on close. Availability, ads and latency remain controlled by YouTube/the provider.
- Pin is the Nana station / Soi 11 area, not a surveyed camera location.
- [BMA Traffic](https://cpudapp.bangkok.go.th/bmatraffic/) is linked as an official directory. It returned browser verification/availability errors during this review; no BMA stream is claimed to work in the app.
- The inspected Jack's Bar video was unavailable and was excluded. Highway camera pages with multi-year-old image timestamps were excluded.

## Service-data boundary

No continuous operator delay or train-position feed is connected. The Delays panel shows coverage, official links, collection-fetch time and verified report review/publication timestamps when supplied. Empty or stale data must never imply normal service. Existing validated station notices remain persistent and independent of the animation clock.

SRTET's own [RSS documentation](https://www.srtet.co.th/en/single-page/7) points to https://www.srtet.co.th/rss/news/group/12. The feed returned only 2024 and 2022 promotional items during this review. It was not integrated as live disruption information. Existing operator source allowlists remain in use; no encrypted or undocumented operator API was reverse engineered.

## Validation

- Railway model checks: 69,589 sampled states, 11 services, no track gaps, no trains at 02:00.
- Alert regression suite: provenance, station scope, expiry, outages, explicit resolution, injection protection and persistent markers passed.
- Netlify preview inspected at desktop size and 390 × 844: full map, six dock actions, mobile navigation buttons hidden, service coverage, camera playback, camera cleanup, Nana station search/details, Night settings and fare dialog.
- Earlier local browser launch was unavailable; actual UI checks used the HTTPS Netlify preview.
- UI inspiration: [Mini Tokyo 3D](https://minitokyo3d.com/). No source code or media from that site was copied.

## Security

Existing restrictions remain. CSP adds only youtube-nocookie.com for the embedded player and i.ytimg.com for camera thumbnails. Camera/microphone/geolocation permissions remain denied. External links use noopener/noreferrer. The app does not request the viewer's physical location or webcam.

The optional Powered by Netlify badge was disabled through the project setting because it covered the mobile dock. The production HTML then matched the published build byte for byte.
